# 🚆 Railway Reservation System

### Database Management System Project using MySQL

## 📌 About the Project

The Railway Reservation System is a database management project developed using MySQL. It is designed to manage railway-related information, including train details, passenger records, seat availability, and ticket bookings.

The project demonstrates how a relational database can be used to organize railway reservation data and perform operations such as booking management, passenger information retrieval, seat availability checking, and booking status verification.

This project provides practical experience with SQL queries, database design, table relationships, and stored procedures.

## 🎯 Objectives

* To design and implement a railway reservation database.
* To maintain train and passenger information.
* To manage seat availability and reservation records.
* To perform ticket booking and booking status operations.
* To retrieve useful information using SQL queries.
* To understand database management concepts through a practical application.

## ✨ Features

* 🚆 **Train Management:** Stores train information and related details.
* 👤 **Passenger Management:** Maintains passenger records.
* 💺 **Seat Management:** Stores seat details and availability status.
* 🎫 **Booking Management:** Maintains ticket booking information.
* 🔍 **SQL Queries:** Retrieves booking, passenger, train, and seat information.
* ⚙️ **Stored Procedures:** Supports database operations through stored procedures, including ticket booking where implemented.
* 📊 **Database Reports:** Allows retrieval of useful information through SQL queries.

## 🗄️ Database Components

The database contains the following main tables:

| Table      | Purpose                                           |
| ---------- | ------------------------------------------------- |
| TRAIN      | Stores train information.                         |
| PASSENGERS | Stores passenger details.                         |
| SEATS      | Maintains seat information and availability.      |
| BOOKING    | Stores ticket booking records and booking status. |

## ⚙️ How to Run the Project

1. Install MySQL Server and MySQL Workbench.
2. Open MySQL Workbench and connect to your MySQL server.
3. Open the provided `.sql` script.
4. Review the SQL statements and execute them in the appropriate order.
5. Select the railway reservation database.
6. Run the queries to view train, passenger, seat, and booking information.
7. Test the stored procedure if it is included in the selected script.

**Important:** If you use the database export file, check whether it contains the schema and data required to run the project.
